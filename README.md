# SDL Software Workbooks
This repository contains working examples that are relevant to the efforts of the KSU AstroFlashes SDL Software subsection team.

> [!NOTE]
> By no means are these workbooks exclusive *to* the Software subsection team!
> **Anyone** with an interest in understanding the software concepts presented here is encouraged to try the workbooks!

## Python
Python must be installed to follow any of the *python-\** workbooks.

### Option A (recommended for KSU AstroFlashes SDL Software team members)
Follow the instructions in [sdl-sw-development](https://github.com/KSU-AstroFlashes-SDL/sdl-sw-development) to get your [Dev Container](https://containers.dev/) set up.

The dev container already has `python`, `pipx`, `ruff`, and `uv` installed. You should be able to follow any of the *python-\** workbooks within the running container.

### Option B (recommended if you just want to complete the workbook locally as a learning exercise)
[Download Python](https://www.python.org/downloads/) and install it.  Be sure to **enable** the option to "Add Python to your PATH."

You should now be able to follow any of the *python-\** workbooks.
